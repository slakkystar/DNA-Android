## Введение

### Назначение
- Используйте этот фреймворк для быстрого создания инструментов для работы с устройством, обладающих ROOT-правами, с помощью `xml + shell`
- Если у вас есть определённые знания синтаксиса скриптов `linux shell`, освоиться будет очень быстро
- В большинстве случаев достаточно изменить статические файлы в `assets` приложения, чтобы завершить определение и изменение функций
- Без необходимости изменять и компилировать код на `Java, Kotlin`

### Демонстрация интерфейса
- Перед началом стоит сначала взглянуть на интерфейс.
- Также можно скачать последний установочный пакет release
- Посмотрите, как это работает, на вашем устройстве с ROOT или эмуляторе
