## Introduction

### Purpose
- Use this framework to quickly create tools for working with devices that have ROOT permissions, using `xml + shell`
- If you have some knowledge of `linux shell` script syntax, you'll get up to speed very quickly
- In most cases, it's enough to modify static files in the app's `assets` to complete the definition and modification of features
- No need to modify and compile `Java, Kotlin` code

### Interface Demo
- Before starting, it's worth taking a look at the interface first.
- You can also download the latest release installation package
- See how it works on your ROOT-enabled device or emulator
- [Published Release Versions](https://github.com/slakkystar/DNA-Android/releases)
